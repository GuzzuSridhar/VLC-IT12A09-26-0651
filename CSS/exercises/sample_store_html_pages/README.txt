Sample Store HTML pages

Files:
- login.html: a centered login card.
- products.html: a product listing with 3 columns × 3 rows on desktop.
- style.css: shared styling and responsive layout.

How to run:
1. Extract this ZIP file.
2. Open the folder in VS Code.
3. Open login.html with Live Server, or open the HTML file directly in a browser.
4. Use Login / Products in the navigation to switch between pages.

Notes:
- Product images are loaded from Unsplash, so an internet connection is needed for the images.
- Login and Add to cart are demonstration UI only; no authentication or cart backend is connected.
